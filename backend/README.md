# IMovies backend
Express API starter. Copy `.env.example` to `.env`, configure MongoDB and a strong JWT secret, then run `npm install` and `npm run dev`.
Routes: `GET /api/health`, `GET/POST /api/movies`, `GET/POST/DELETE /api/bookings`, `POST /api/auth/register`, `POST /api/auth/login`.
This is a starter project, not a production-ready ticketing/payment system. Add authentication middleware, seat-locking transactions, validation, rate limits, and payment integration before real-world use.
